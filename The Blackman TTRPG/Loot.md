Loot is represented by a dice. When rolling on a loot table, you add each grade inclusively. The GM can decide loot pools on a whim and change loot pools as well.


| Identifier | Loot Level                                     |
| ---------- | ---------------------------------------------- |
| Common     | 1d4                                            |
| Uncommon   | 1d8                                            |
| Rare       | 1d10                                           |
| Epic       | 1d14                                           |
| Legendary  | 1d16                                           |
| Mythic     | 1d18                                           |
| Cosmetic   | Not included in regular rolls, roll alongside. |

Loot Value (LV) = time cost of materials (M) + time cost of labor (L) * skill used (S)
Loot Sell Value (LSV) = LV * (demand d* supply s)
