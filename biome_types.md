Biomes represent a geographical area that maintains similar aspects, such as being vegetation dense, with a large canopy of trees (Jungle). These biomes are crucial to the "flow" of the world, as they allow you to imagine landscapes and maintain continuity between hexes.

When a hex is adjacent to another biome, roll 1d6 and use the result from the following table. If a hex is adjacent to multiple biomes roll Xd8s (where x is equal to how many adjacent biomes there are), then take the most occurring biome within that. 

| **Biome Action** | **Roll** |
| ---------------- | -------- |
| Keep the same    | 1        |
| Keep the same    | 2        |
| Keep the same    | 3        |
| Change Biome     | 4        |
| Change Biome     | 5        |
| Reroll           | 6        |
#### Multi-Adjacency Roll Table
The multi adjacency roll table will be filled up with an equal number of each biome (that are adjacent) then any remaining spaces will be filled with "reroll". Below is an example of a 3 biome split.

| **Biome Action** | **Roll** |
| ---------------- | -------- |
| Biome 1          | 1        |
| Biome 1          | 2        |
| Biome 2          | 3        |
| Biome 2          | 4        |
| Biome 3          | 5        |
| Biome 3          | 6        |
| Reroll           | 7        |
| Reroll           | 8        |

### Biome Bonuses
A Biome Bonus is a +/- added to the end of geological features.
