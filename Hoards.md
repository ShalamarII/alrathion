A hoard is an abstract way of representing a resource.

If you roll a 1, the dice's size is reduced (Using rations, using a money, spell components being consumed).

If you roll a 2 or above everything stays the same (Replenishing rations, using a negligible amount of money, etc.).

| *Size Name*            | *size* | *Actual Probability* |
| ---------------------- | ------ | -------------------- |
| Small (Personal Size)  | 1d4    | 25%                  |
| Medium (Backpack Size) | 1d6    | 16%                  |
| Large (Trunk Size)     | 1d8    | 12.5%                |
| Huge (Vault+ Size)     | 1d12   | 8.33%                |
