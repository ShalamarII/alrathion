Uses concepts from: WebDM & CitanulsPumpkin

Inventory items are abstracted and given a dice to roll against instead.

If you roll a 1 or a 2, the dice's size is reduced (Using rations, using a money, spell components being consumed).

If you roll a 3 or above everything stays the same (Replenishing rations, using a negligible amount of money, etc.).
