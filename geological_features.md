Geological features (GeoF for short) are features such as rivers, mountains, ponds, cliffs, etc. Generation of these is applied through 1 round of placing initial features, disregarding biome bonuses and then subsequent rounds generating tiles, accounting for biome bonuses.

### Biome Bonuses
A biome bonus is a modifier to the geological feature table applied at the end of calculation. This allows the world to maintain somewhat continuous geological features.

```

For example, if you had 8 GeoFs and an equal distribution roll expression (1d8), then if the bonus for a Plains is +2, instead of rolling a 1d8, you'd roll 1d8+2 and take the result instead.

```
